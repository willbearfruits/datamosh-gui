Capabilities
What it does

Full creative control over the AVI bitstream — no decoding, no re-encoding, pure binary chunk manipulation at codec level.

☰
Multi-clip timeline
Sequence any number of clips on an NLE-style timeline. Each segment has independent mosh settings.
⚠
Drop I-frames
Remove keyframes at clip boundaries to let compression bleed across cuts. The core datamosh operation.
∞
Duplicate P-frames
Repeat delta frames to smear motion, freeze movement artifacts, and create motion blur-like trails.
▶
Live preview
300 ms debounced re-mosh pipeline. See the glitch output update in real time as you adjust settings.
↻
Full undo / redo
Every clip operation is tracked in an O(1) deque-backed undo stack. Nothing is permanent.
⇄
Drag and reorder
Drag clips in the panel, split at playhead, rearrange sequences. Clip list and timeline stay in sync.
⇅
Import any format
Anything ffmpeg reads gets normalised to Xvid AVI automatically on import. No manual conversion.
✎
Per-clip control
Keep first frame, set duplicate count and gap, toggle keyframe drop — all independently per segment.
▶│
CLI standalone
The mosh engine is a plain Python script. Use mosh.py directly in shell pipelines without the GUI.
Changelog
What's new in v1.1.5

Stability, resource hygiene, and interaction fixes across all platforms.

perf
No more /tmp bloat
Temporary directories created during import are now cleaned up when a clip is removed from the project.
ux
Background video probing
Video metadata is probed off the main thread. The UI no longer freezes during import of large files.
ux
Scroll wheel pans timeline
Scroll wheel now pans the timeline horizontally. Ctrl + scroll wheel zooms. More natural NLE behavior.
ux
Clip list syncs on timeline click
Clicking a clip block in the timeline now also highlights the corresponding entry in the clip list panel.
ux
Settings panel locked when no clip selected
The settings panel is now disabled when no clip is selected, preventing stray changes from being applied.
fix
UpdateWorker crash fix
Resolved a race condition in the update worker that caused crashes when switching clips rapidly.
fix
OpenCV handle leak (Windows)
Fixed a file handle leak in the frame extractor on Windows that accumulated open handles over long sessions.
fix
Render dialog stops worker on close
Closing the render dialog now properly terminates the background render worker instead of leaving it orphaned.
perf
Undo stack O(1) with deque
The undo history is now backed by a bounded deque, eliminating memory growth with long sessions.

CLI engine
Use without the GUI

The mosh engine is a self-contained Python script. Drop it into any pipeline — no GUI dependencies required.

# basic datamosh — drop I-frames, keep first frame $  python3 mosh.py input.avi output.avi --keep-first 1   # duplicate P-frames for motion smear $  python3 mosh.py input.avi output.avi --duplicate-count 8 --duplicate-gap 3   # normalise any format to Xvid AVI first $  python3 mosh.py input.mp4 output.avi --normalize --keep-first 1 --drop-keyframe

Requires ffmpeg + ffprobe on PATH. Output is always Xvid AVI.
